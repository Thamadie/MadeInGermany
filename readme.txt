An animated WooCommerce theme for a shop selling German products in Sri Lanka.

== Installation ==

1. Install and activate WooCommerce (Plugins → Add New).
2. Appearance → Themes → Add New → Upload Theme, choose made-in-germany.zip, then Activate.
3. Appearance → Made in Germany demo → "Import demo products".
   Leave the box ticked to also set the store to rupees (LKR, no decimals),
   Sri Lanka as the store country, a Sri Lanka delivery zone (Rs 450, free over
   Rs 15,000) and cash on delivery + bank transfer.
4. Settings → Permalinks → choose "Post name" and save.
5. WooCommerce → Settings → Site visibility → choose "Live" when you are ready
   (new WooCommerce stores start in "Coming soon" mode and hide the shop).

== Customising ==

Appearance → Customize → Made in Germany:
- Announcement bar messages
- Home hero text and the three stats
- Deal of the day banner (title, text, which categories the button opens)
- Free delivery threshold (keep it the same as your Free shipping rule)
- "New" label duration
- Newsletter text and an optional form shortcode (e.g. Mailchimp for WP)
- Footer address, phone, opening hours, WhatsApp chat button, copyright

Menus (Appearance → Menus): "Header menu" and "Footer help menu".
Without menus, the theme shows Home / Shop / Deals and account/cart links.

== Products ==

Extra fields on each product (Product data → General):
- Made in (city), Maker / brand, Size / pack, Emoji (shown until you add a photo)

"Made in regions" (Products → Made in regions) power the region filter.
Product categories have an emoji icon and tile colour (Products → Categories).
Mark a product as Featured (the star in the product list) to label it "Bestseller".

== Shop filters ==

The shop page filters by category, price (slider with price spread chart),
customer rating, on sale / new / bestseller / saved items, and German region.
Results update without reloading the page, and every filter state has its own
link that can be shared, e.g. /shop/?cats=chocolates&on_sale=1

Saved items (the heart) are kept in each visitor's browser.

== Payments ==

Cash on delivery and bank transfer are built into WooCommerce. For card
payments in Sri Lanka, install a payment gateway plugin such as PayHere.

== Checkout ==

Sri Lankan addresses ask for one of the 25 districts, and phone numbers are
checked for a Sri Lankan format (classic and block checkout).
